ACADEMIA - install as an app
1. Upload ALL files in this folder to any free HTTPS host (Netlify Drop, GitHub Pages, Cloudflare Pages).
2. Open the hosted link in Chrome on your Android phone.
3. Tap the 3-dot menu > Install app (or Add to Home screen).
Academia then opens full screen like a normal app and works offline.
Unlock with your 6-digit access code. Optional: tap Create Account on the main screen to add school name, email and identity code.
Data is saved on the device.
